# Avtomaktab — сайт автошколы + CRM обзвона + билеты ПДД

Готовый продукт для автошколы (white-label: одна кодовая база — много школ).

**Для ученика (UZ / RU):**
- Главная: курсы и цены, этапы обучения, отзывы, филиалы, FAQ, заявка в 2 поля
- Билеты ПДД: тренировка по билетам и темам с пояснениями, режим «Экзамен» (как в ГАИ: N вопросов, таймер, лимит ошибок), «Мои ошибки»
- Библиотека: учебники и PDF — читать онлайн или скачать
- После теста — форма записи на вождение (источник «после теста» виден в CRM)

**Для менеджера:**
- **Обзвон** — очередь: сначала свежие заявки, потом те, кому пора перезвонить. Большая кнопка звонка, Telegram, история, результат звонка в один клик, «перезвонить через 2 часа / завтра / через 3 дня», «Сохранить и к следующему»
- **Заявки** — фильтры (статус, менеджер, курс, источник, даты), поиск по имени/телефону, выгрузка в Excel, ручное добавление (звонок, Instagram, офис)
- Менеджер видит только свои и свободные заявки; админ — всё

**Для владельца (админ):**
- Аналитика: заявки по дням, воронка, конверсия, скорость первого звонка, менеджеры, источники, спрос по категориям, статистика тестов
- Билеты ПДД: редактор вопросов с картинками, **импорт/экспорт Excel** (шаблон внутри)
- Курсы, филиалы, библиотека (загрузка PDF), отзывы, FAQ, темы
- Настройки: название, логотип, цвета бренда, контакты, тексты главной, цифры, правила экзамена, **уведомления о заявках в Telegram**
- Сотрудники и роли

Защита от спама (honeypot + лимит), склейка дублей заявок за 24 часа, UTM-метки.

## Стек
Next.js 15 (App Router) · TypeScript · Tailwind · Prisma 6 + PostgreSQL · JWT-сессии · ExcelJS · Recharts.
Файлы (PDF, картинки, логотип) хранятся в PostgreSQL — volume на Railway не нужен.

## Запуск локально (Windows / PowerShell)
```powershell
npm install
copy .env.example .env      # впишите свой DATABASE_URL
npx prisma db push
npm run db:seed             # демо-контент + админ admin / admin12345
npm run dev
```
Сайт: http://localhost:3000 · Админка: http://localhost:3000/admin

## Деплой на Railway
1. Залейте репозиторий на GitHub → в Railway **New Project → Deploy from GitHub**.
2. Добавьте сервис **PostgreSQL** в тот же проект.
3. В переменных сервиса приложения:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
   - `JWT_SECRET` = длинная случайная строка
   - `ADMIN_LOGIN`, `ADMIN_PASSWORD` — первый админ
4. Deploy. При старте автоматически создаются таблицы (`prisma db push`), демо-данные и админ — только если база пустая. Повторные деплои данные не трогают.
5. Settings → Networking → Generate Domain (или свой домен).

**Сразу после деплоя:** войдите в /admin → Настройки → смените название, телефоны, цвета, логотип; Сотрудники → смените пароль админа и добавьте менеджеров.

## Новая школа (продажа шаблона)
Новый проект на Railway из того же репозитория + своя база → всё остальное настраивается в админке без кода.

## Билеты ПДД
В комплекте 20 демо-вопросов (2 билета). Официальную базу загрузите через **Билеты ПДД → Импорт из Excel**:
скачайте «Шаблон Excel», заполните (один вопрос — строка, `correct` — номер правильного ответа), загрузите.
Можно поставить галочку «Заменить все текущие вопросы».
